# Wind Lover

[ゲームをひらく](https://hane-san.github.io/wind-lover/)

馬に乗り、中央アジアの遺構を旅する3Dブラウザーゲーム。サイドカーなどの乗り物も選べます。砂漠の廃線、雪へ昇る山道、夕暮れへ向かう湖の一周、青い都へ続く隊商路、赤い峡谷と草原の未来都市を中心に、盆地と峠をつなぐ120kmの世界を走れます。

開始画面とメニューの先頭から、ウズベキスタンの砂漠の廃線、ビシュケク〜オシュを思わせる山道、イシク・クルの周回、ドゥシャンベ〜サマルカンドの隊商路、草原からアスタナへ、シャリンを思わせる赤い峡谷へ、六つのアイコンから出発できます。選択前のアイコンは中立色で、現在の出発地点だけ印が付きます。

標準はキルギス風の馬と、大パノラマの遠景カメラ。馬より下からドラッグすると移動、敵の近くを触ると小さい印でロックし、敵と馬の間に現れる白い反曲弓が、馬へ、または横へ引く指に合わせてしなります。弦が白く張るまで引いて離すと、軌跡を残す矢を放ち、一撃で倒せます。二本の指で移動と弓を同時に操作できます。PCでは A・D で操舵、W で前傾、S でブレーキ、マウスで同じ弓の操作。メニューから襲撃をオフにすると、風景を見ながら走れます。スマートフォンの縦画面に対応しています。四地域には本線へ戻れる幅56〜96mの周遊路を追加し、合計約20kmの寄り道を楽しめます。

馬は道に沿いながら左右の走行ラインを選べます。分岐では合流先を先読みし、近い道へ突然向き直らないようにしています。湖岸の赤い岩と並木、草原の白い地層や隊商路の果樹が旅路に変化を添えます。静かな湖岸走行では視線をわずかに湖へ寄せ、弓や回避の操作で正面へ戻します。強い切り返しで低く跳び、脚を踏み替えます。キーボードでは Space で跳躍。接地に合わせた土埃や雪煙と、画面中央を空けた風の筋が疾走感を添えます。湖の東岸から峠へ、峠の出口から砂漠へ続く廃線へ、古い案内標をたどって走って移動できます。草原の廃線からは、巨大な塔と大きな天幕が現れるアスタナ風の未来都市へ分岐。幅64mの大通りを駆け抜けて廃線へ戻れます。湖岸と峠の分岐からは幅64m・約29.8kmの峡谷道でアスタナへ抜けられ、元の廃線・隊商路とも地続きにつながっています。赤い岩塔と川、峠を下った先の渓流と針葉樹の谷を追加しています。山道は標高に応じて緑から雪へ変わり、湖は西へ回り込んだ後に夕日から星空へ移ります。

スタート画面・メニューの「旅の門」から、日本・東南アジアを凝縮した14エリアへワープできます。豊洲の運河、夕暮れの江戸の田畑と宿場、アンコールの遺跡とその奥、カオサン、ドンムアン、マレー半島の海岸に、現代金沢、四国の渓谷、北の森と湖をめぐるアイヌ文化の景色、ハジャンの岩山、タイの水郷、琉球の赤瓦と城壁、沖縄の港町を追加。外周だけでなく、少し広げた24本の道と広場を結ぶ約26.3kmの網を、分岐で進路を選んで旅できます。現実の位置関係から自由に組み合わせた世界です。藍の装束と笠の弓兵、折り紙の翼の無人機などへ外観を変え、走行・弓の操作は共通です。

手綱を倒している間は道の引き戻しを弱め、端では短い入力によるコースアウトをやわらかく防ぎます。強く長めに倒せば道を離れて探索もできます。分岐の手前で左右の手綱を約1秒保つと進路を選びます。短い左右入力は回避に使え、下方向＋左右なら道を離れて探索できます。メニューの「旅の地図」で道のつながりと現在地を確認でき、14の丸から出発地点へ移動できます。元の中央アジアの旅の場所へ戻れます。

メニューの「旅の音楽」で、38曲のオリジナルBGMのオン・オフ、土地に合うおまかせ再生・手動選曲、音量を変えられます。初回はオンで、出発操作から再生し、設定は次回にも引き継がれます。金沢の揺れる鍵盤、四国の7拍子、北の森の笛、ハジャンの角笛に加え、江戸の琴を思わせる撥弦と、遺跡の木琴の2曲も追加。土地ごとのテーマと近い雰囲気の曲を中心に再生します。日本・東南アジアでは、走ってエリアを越えると土地ごとの曲へ3秒かけて移り変わり、同じエリアを走り続けても曲が変わります。江戸の茜空にはカラス、南の海には海鳥。空の色、薄雲・明るい雲、遠景の霞や土・苔・海岸道の色も土地と時間に合わせて変わります。中央アジアの選曲と効果音の切り替えも引き続き使えます。

襲撃をオンにすると、文明崩壊後の無人警戒網が起動します。前方の高低差のあるドローン編隊と道脇の無人砲台から、空に弧と幾何学模様を描くミサイルが三回。かわしながらテンポよく弓を返し、近づきすぎると短いマシンガンの連射が始まります。ミサイルを左右に避けつつ弓で倒し切ると、静かな景色の時間へ戻ります。加速とカーブ後の立ち上がりを高めながら弓を引く余裕を残し、蹄音、土埃、風と遠景で疾走感を補っています。小さい自機判定で弾の隙間を抜け、かすめると勢いが増します。地形の継ぎ足しはフレーム間に分散し、負荷に合わせて描画解像度も調整します。

ローカルで起動する場合は、リポジトリのルートで `python -m http.server 8000` を実行し、`http://localhost:8000/` を開いてください。Three.js とフォントはCDNから取得します。

検証は Python の Playwright と Chromium を用います。`python tests/world-smoke.py --browser /usr/bin/chromium` で実行できます。Three.jsをローカルに用意した場合は `--three /absolute/path/three.min.js` を指定できます。

音楽の検証は `node --test tests/music-scores.test.mjs` と `python tests/music-browser.py --browser /usr/bin/chromium` で実行できます。後者は NumPy と FFmpeg も使用し、実際のゲームの出力を録音して、描画停止中・曲の切替中の無音を調べます。同じ `--three` オプションを使えます。

回避と生成処理の検証は `python tests/dodge-browser.py --browser /usr/bin/chromium` です。同じ `--three` オプションを使えます。敵弾との高速な交差、グレイズ、実走行での回避、9種類の弾幕、生成の分割・中止、解像度の適応を確認します。
