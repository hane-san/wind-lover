# 馬と遠景、土地に合う音楽（2026-10-22）

「乗り物」の **キルギスの馬** を選ぶと、サイドカーと同じ巡航・最高速度、加速、操舵、当たり判定で走れます。馬の速度はこのゲームの幻想的な設定です。カルパック風の白いフェルト帽、青緑の長衣、赤い帯、既存の羊角文様の鞍敷、革の手綱と鐙を組み合わせています。四肢・膝・首・尾と騎手が一歩の周期に合わせて動き、エンジン音と排気の代わりに風と蹄の音が聞こえます。タレットは起動できず、他の乗り物から切り替えた際も武器と未着弾の自機弾を解除します。選択は保存されます。

文化的な手がかりは [UNESCOのカルパックの記録](https://ich.unesco.org/en/RL/ak-kalpak-craftsmanship-traditional-knowledge-and-skills-in-making-and-wearing-kyrgyz-men-s-headwear-01496) と [シルダック／アラ・キイズの記録](https://ich.unesco.org/en/RL/ala-kiyiz-and-shyrdak-art-of-kyrgyz-traditional-felt-carpet-making-00693) を参照しています。衣装・馬具を含めたゲーム上の造形は創作で、特定時代の完全な復元ではありません。

## 音楽

既存4曲に、下記のオリジナル8曲を追加しました。

| 曲 | 主な地域 |
|---|---|
| 銅色の蜃気楼 | 砂漠 |
| 忘れられた側線 | 廃線・都市 |
| 天山を越える風 | 山道 |
| 雪明かりの峠 | 雪・山道 |
| イシク・クルの朝凪 | 湖岸 |
| 湖岸に残る夕映え | 湖岸・都市 |
| ジャイローの草を分けて | 草原 |
| フェルトと星の道 | 草原 |

初期の選曲は「おまかせ：この土地に合う曲」。砂漠・山道・湖・草原・都市ごとに4曲の候補があり、訪問時に直前と違う1曲を抽選します。走行中は実際の地形から地域を判定し、12秒以上同じ地域が続いたときに切り替えます。同じ場所でメニューを開くだけでは再抽選しません。手動で曲を選ぶと自動選曲を止め、手動／おまかせのモードも保存します。オン・オフと音量の既存設定は継承します。

`music/scores.mjs` が楽譜、`music/route-playlist.mjs` が選曲です。追加曲は `python tools/render-music.py` でNumPy／SciPyからOggとPCM WAVに書き出せます。Node・FFmpegも使用します。既存4曲の音源は変更しません。各曲は約42〜75秒で、循環した残響・リリース、8msの継ぎ目補正、音量の正規化を済ませています。実行時は既存の音声クロックとクロスフェードを使用し、曲を読み込む間は前の音源が流れ続けます。

## 弾と景色

敵弾の丸い光粒を、濃い外枠と明るい面のある菱形に変更しました。解像度低下時も最小の画面上サイズを保ちます。花弁状の弾幕は二重の菱形に、曲線の織物は角のある折線に変更。九種類の模様と回避できる通路、0.32mの連続当たり判定、グレイズは維持しています。

三つの旅路では、ユルトの集落、バルバル風の石像列と塔、隊商宿、途中が欠けた水道橋を交互の方向・距離へ追加。道路を走り続けても、曲がるにつれて異なる輪郭が視界に入ります。建物は道と廃線から離し、新しい建物の衝突面は各部分に対応させています。常時表示する案内やHUDは増やしません。

草原はセージ色・オリーブ・枯草色、雪は青い陰と暖かな白を、位置から連続的に混ぜます。同じ関数を地面・草・遠景の地面に使い、区画ごとの乱数で色を変える方法は避けています。

## 2026-10-22：余裕を持った馬の走り（初回調整）

脚の回転を走行距離へ直接結び付ける方式をやめました。従来は40m/sで約4.2周期／秒、80m/sで約8.4周期／秒でしたが、新しい見た目の周期はそれぞれ約1.16、約1.47周期／秒、上限1.55周期／秒です。移動速度・加速・入力・当たり判定は変更しません。

`world/horse-gait.js` が見た目専用の時刻を管理します。後肢で押し、前肢を伸ばし、全ての脚が宙にある間を一周期の約2割取ります。足先の移動経路から上肢と膝の角度を求め、脚を畳む過程と前へ伸ばす過程を滑らかにつなぎます。胴・首・騎手は一周期に一度の穏やかな動きへそろえ、バイクの細かい振動と傾きは馬だけ控えめにします。蹄の音は同じ周期の三拍にまとめ、連打が続かない間を作っています。

停止と空中では周期を進めず、脚の動きの大きさを滑らかに落とします。メニューの一時停止でも脚や音は進みません。この動きはオリジナルで、既存ゲームのモーションデータは使用していません。

追加の `node --test tests/horse-gait.test.mjs` は、20／30／60／120fpsでの周期の一致、速度上昇時の上限、全四肢の連続した足先の軌跡、接地・浮遊の間、停止・一時停止・空中時の抑止を検証します。Chromiumでは一周期の12姿勢を描画し、既存の乗り換え・走行性能・武器抑止の検査も実行します。

## 2026-10-22：軍馬が駆け抜ける踏み込み（現行）

上の初回調整を更新し、ゆっくりした三拍から、後肢二本・前肢二本が順に接地する四拍へ変更しました。見た目の周期は40m/sで約1.71、80m/sで約2.02周期／秒、上限2.1周期／秒です。実際の移動速度・加速・操舵・当たり判定は維持します。

前肢の膝に加え、後肢には膝と飛節を分けた三節の骨格を設け、前肢とは異なる曲がり方にしています。腰と後躯を厚くし、後肢で押し出す姿、前肢で体重を受ける姿、四肢が浮く間が続きます。胴体の前後傾を含めて足先の角度を解き、騎手は鞍の高さを支点に前傾、尾は後方へ流します。

接地順の参考は[ミネソタ大学獣医学の横襲歩の解説](https://vanat.ahc.umn.edu/gaits/transGallop.html)、前後肢の役割の参考は[馬の襲歩時の地面反力に関する研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2696142/)です。造形・軌跡・音はいずれもこのゲーム用の創作で、実馬の計測データや既存ゲームの素材は使用していません。

`world/horse-sound.js` は、硬い蹄鉄の立ち上がり、空洞のある蹄の響き、低い着地音を合成します。四本で音色・重み・左右の位置を少し変え、道路では硬く、草地では柔らかく鳴らします。馬の風音を少し抑え、蹄音が聞こえる配分にしました。音声バッファは初期化時に八つだけ作り、終了した音声ノードは解放します。接地のフレーム内時刻を音声クロックへ渡すことで、低い描画fpsでも二つの蹄が同時に鳴ることを防ぎます。

```sh
node --test tests/*.test.mjs
python tests/horse-charge-browser.py --browser /path/to/chromium
python tests/travel-upgrade-browser.py --browser /path/to/chromium --three /path/to/three.min.js
python tests/music-browser.py --browser /path/to/chromium --three /path/to/three.min.js
```

単体試験は四拍の順番、全四肢の足先と骨格の一致、連続性、停止・空中・一時停止での抑止、音の有限値・端点・音量・路面差を検査します。実際のChromiumのOfflineAudioContextでは20／30／60／120fpsで各15回の接地音を描画し、発音時刻差3ms未満、音割れや発音の欠落がないこと、音声ノードの解放を検証します。ブラウザーの走行試験で馬とサイドカーの同一速度・位置、武器抑止、設定保存とページエラーも再検査します。
