# 背の高い馬と、真後ろを軸にした旅の視点（2026-10-22）

「広い世界をただ一人、高速で駆け抜ける疾走感と物悲しさ」を両立するため、淡い景色・全12曲・「ぱからっ」の蹄音を引き継ぎ、馬の造形とカメラを更新しました。

## 馬の造形

胴・首・頭を別々の丸い球で組む形から、断面をつないだ滑らかな輪郭へ変えました。胴を引き締め、首から細長い顔へつなぎ、小さな目と鼻孔、細い鬣、曲線の尾、細い管部と小さな蹄を付けています。毛色は落ち着いた鹿毛風。キルギス風の鞍敷と衣装は維持します。手綱は手と動く馬の口元を結び、少したわみます。

造形上の脚の付け根は1.10から1.48m、胴幅は約0.96から0.84m、騎手の帽子の頂点は約3.38から3.70mへ変更。これはゲーム内の造形寸法です。乗り物全体を拡大するのではなく、脚・胴・首・顔と鞍の位置をそれぞれ調整しています。走行速度・操舵・衝突半径は変更しません。

`world/horse-gait.js` の共有骨格寸法を造形と足先の逆運動学に使い、長い脚でも接地を一致させます。四拍の順序、まとまりと間、歩調は [HORSE-GALLOP.md](HORSE-GALLOP.md) のままです。鞍の支点を新しい高さへ移し、騎手が腰で揺れを吸収する動きも維持します。

## 真後ろを軸にしたカメラ

`world/travel-camera.js` は馬の走行時だけ、後方追従へ小さな変化を足します。出発直後は真後ろ。広い道を穏やかに14秒走ると、12秒ほどかけて斜め後ろへ寄り、少し引いて、再び真後ろへ戻ります。その後も長い中央の視点を挟み、左右を交互に変えます。カメラの横移動は最大約2.2m、引く量は最大約1.65m、上昇は最大約0.28mです。前や真横へ回り込む、視点を切り替える処理はありません。穏やかな曲がりには小さな先回りも加えています。

強い舵、低速、空中、トンネル、道路端や狭い道、被弾直後、敵の接近では中央へ滑らかに戻し、落ち着いた走行が続くまで次の変化を待ちます。出発地点・世界・乗り物を変えれば状態をリセットします。メニュー中は時計も動きません。追加のボタンやHUDはありません。

## 検証

```sh
node --test tests/*.test.mjs
python tests/horse-presentation-browser.py --browser /path/to/chromium --three /path/to/three.min.js --out /tmp/horse-presentation
python tests/travel-upgrade-browser.py --browser /path/to/chromium --three /path/to/three.min.js
```

Nodeでは全16試験で足先・接地音・騎手・選曲に加え、中央の視点が主体であること、左右への変化の上限・速度、入力と危険による復帰、停止・リセット、20／30／60／120fpsの一致を検査します。実際のWebGLでは120姿勢の蹄の位置と計算上の接地を照合し、頭の上下幅、カメラが後方に留まること、操舵・空中・トンネル・敵・世界変更による復帰を検査します。湖・雪山・砂漠と、真後ろ・斜め後ろの画面も描画します。

iPhone/Safari実機での手触り、視点の好み、発熱時の性能は未確認です。
