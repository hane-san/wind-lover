# 遠景を見比べるカメラ調整（2026-10-23）

2026-10-24の騎射改修で、標準を「大パノラマ」に変更しました。手動調整済みの構図は保持します。[最新の操作と保存値](BOW-RIDING.md)も参照してください。

メニューの手ざわり調整に、画角・高さ・上下の角度を追加しました。既存の距離も同じ場所にまとめ、縦横比が実際の走行画面と同じプレビューで、同じ場所の構図を見比べられます。移動、馬の動き、景色の時刻は停止したまま、カメラだけが新しい値へ滑らかに寄ります。「走りに戻る」でその視点を引き継ぎます。

| 調整 | 範囲 | 初期値 |
| --- | --- | --- |
| 画角（垂直FOV、通常時） | 縦48〜112度、横34〜98度 | 縦112度、横98度 |
| カメラの高さ | 支点から2〜28m | 20m |
| 上下の角度 | 標準から−14〜＋20度 | −5度 |
| 空と大地の配分 | 空側12%〜大地側22%の画面移動 | 大地側8% |
| カメラの距離 | 基準4〜36m | 全乗り物14m |

角度は負で空、正で足元へ向きます。高さを変えた後の標準の注視点を基に角度を加えます。画角には従来の速度による広がりも加わります。画角は標準からの差として保存し、端末の縦横を変えたときも広げた度合いを保ちます。距離は従来どおり速度・景色・襲撃による補正を受けます。高さは地面や壁、トンネルの天井を避ける処理を優先します。

保存キーは既存の `windlover.settings.v11` のまま。各乗り物に `camFov`（画角の差）、`camHeight`、`camTilt`、`camFrame`（画面内の上下位置）を追加し、古い未調整の保存は大パノラマへ移し、手動調整済みの保存で欠けた項目には従来の補完値を使います。従来の速度や操舵の保存値は変えません。「視点を初期値へ」は上の五項目と速度による視野の係数だけを戻し、「すべて初期値に戻す」は従来どおり全項目を戻します。走りの調整と自動加速は折り畳みの中に残しています。

プレビューは既存のWebGL描画を小さな2Dキャンバスへ毎秒最大10回コピーします。追加のシーン描画やレンダラーは作らず、調整画面が閉じている間はコピーしません。

```sh
node --test tests/*.test.mjs
python tests/camera-tuning-browser.py --browser /path/to/chromium --three /path/to/three.min.js --out /tmp/camera-tuning
python tests/journey-camera-browser.py --browser /path/to/chromium --three /path/to/three.min.js
```

実際のWebGLと画面操作で、画角・高さ・角度の変化、プレビュー更新、移動・馬・夕暮れの停止、古い保存の補完、再読み込み、乗り換えごとの保存、視点だけのリセット、390×844・844×390・320×568での表示、スライダーの矢印キーと操舵の分離、最大高さのトンネル制限、走行再開を確認します。既存のカメラ試験は敵の接近、壁の手前での停止と復帰も検査します。実際のiPhone/Safariでの操作感と性能は別途確認対象です。

## 写真を出発点にした広がりと比較

従来の保存値と初期値は保持します。三つの視点を呼び出し、そこから各スライダーを動かせます。画角は下表の縦画面の値を基準に、横画面では従来の14度差を維持。走行速度による広がりも引き継ぎ、最終FOVは120度以内です。

| 視点 | 画角 | 高さ | 角度 | 距離 | 空と大地 |
| --- | --- | --- | --- | --- | --- |
| 高め追従 | 90度 | 12m | −3度 | 10.5m | 標準 |
| 遠景ひろめ | 104度 | 16m | −4度 | 12m | 大地側6% |
| 大パノラマ | 112度 | 20m | −5度 | 14m | 大地側8% |

高め追従はユーザーの写真の設定です。高い視点では馬が下へ寄るため、後の二つは画面内の構図も上へ移し、遠景と馬の足元を一緒に見せます。「空と大地」はカメラの実際の高さ・方向を変えず、投影の中心を上下へ動かします。霞、天候、景物の生成範囲や物理には手を加えていません。

「前の視点と比較」は一つ前の構図と現在の構図を往復します。保存するのは表示中の値で、走りの設定は切り替えません。スライダーは指で動かす前、キーで動かす前、視点ボタンは押す前の値を覚えます。「全画面で見比べる」も停止状態のまま。上部のバーから三つの視点を順番に選び、調整画面か走行へ戻れます。小さな画面ではカード内を指でスクロールでき、走行へ戻るボタンは下部へ固定します。

```sh
python tests/camera-panorama-browser.py --browser /path/to/chromium --three /path/to/three.min.js --out /tmp/camera-panorama
```

保存済みの写真の設定を読み込み、三つの構図の横方向の広がり、馬と蹄の画面内位置、空と大地の調整の独立性、可逆比較、停止した全画面表示、次の視点、実際のタッチ入力によるカードのスクロール、閉じた後のモード解除と再開、再読み込み、最大値の有限性とトンネル制限を検査します。湖と雪山の同じ場所で三つの視点を描画して比較します。
