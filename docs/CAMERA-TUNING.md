# 遠景を見比べるカメラ調整（2026-10-23）

メニューの手ざわり調整に、画角・高さ・上下の角度を追加しました。既存の距離も同じ場所にまとめ、縦横比が実際の走行画面と同じプレビューで、同じ場所の構図を見比べられます。移動、馬の動き、景色の時刻は停止したまま、カメラだけが新しい値へ滑らかに寄ります。「走りに戻る」でその視点を引き継ぎます。

| 調整 | 範囲 | 初期値 |
| --- | --- | --- |
| 画角（垂直FOV、通常時） | 縦48〜90度、横34〜76度 | 縦66度、横52度 |
| カメラの高さ | 支点から2〜12m | 4.8m |
| 上下の角度 | 標準から−6〜＋12度 | 0度 |
| カメラの距離 | 基準4〜18m | 馬・サイドカー15m、チョッパー14m、ボード12m |

角度は負で空、正で足元へ向きます。高さを変えた後の標準の注視点を基に角度を加えます。画角には従来の速度による広がりも加わります。画角は標準からの差として保存し、端末の縦横を変えたときも広げた度合いを保ちます。距離は従来どおり速度・景色・襲撃による補正を受けます。高さは地面や壁、トンネルの天井を避ける処理を優先します。

保存キーは既存の `windlover.settings.v11` のまま。各乗り物に `camFov`（画角の差）、`camHeight`、`camTilt` を追加し、古い保存には初期値を補います。従来の速度や操舵の保存値は変えません。「視点を初期値へ」は上の四項目と速度による視野の係数だけを戻し、「すべて初期値に戻す」は従来どおり全項目を戻します。走りの調整と自動加速は折り畳みの中に残しています。

プレビューは既存のWebGL描画を小さな2Dキャンバスへ毎秒最大10回コピーします。追加のシーン描画やレンダラーは作らず、調整画面が閉じている間はコピーしません。

```sh
node --test tests/*.test.mjs
python tests/camera-tuning-browser.py --browser /path/to/chromium --three /path/to/three.min.js --out /tmp/camera-tuning
python tests/journey-camera-browser.py --browser /path/to/chromium --three /path/to/three.min.js
```

実際のWebGLと画面操作で、画角・高さ・角度の変化、プレビュー更新、移動・馬・夕暮れの停止、古い保存の補完、再読み込み、乗り換えごとの保存、視点だけのリセット、390×844・844×390・320×568での表示、スライダーの矢印キーと操舵の分離、最大高さのトンネル制限、走行再開を確認します。既存のカメラ試験は敵の接近、壁の手前での停止と復帰も検査します。実際のiPhone/Safariでの操作感と性能は別途確認対象です。
