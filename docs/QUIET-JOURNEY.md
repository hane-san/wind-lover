# 淡く物悲しい旅へ（2026-10-22）

「レース的な楽しさが前に出すぎる」というフィードバックを受け、絵・音・動きを一緒に調整しました。『トワイライトプリンセス』を、広い景色の中に旅人の孤独が残る、という方向の手がかりにしています。参照した公式の風景は[ラネール地方](https://www.nintendo.co.jp/wiiu/azaj/introduction/map2.html)と[スノーピーク](https://www.nintendo.co.jp/wiiu/azaj/introduction/map1.html)です。既存作品の画像・音源・旋律・モーションデータは取り込みません。

## 絵と視点

空の青・紫・緑の強さを抑え、灰緑、石の灰色、薄い夕映えを中心にしました。地面や建物は色差を残して彩度を少し落とし、暗部をわずかに持ち上げます。光源・水面の照り返し・雲の白さも控えめにしています。地表の霧は280〜3700m、高地では650〜5100mへ連続的に変化し、遠景の輪郭が層になって残ります。草と雪の位置による色差、建物や駅の発見は維持します。

高速を強調する白い速度線を非表示にし、馬の白い軌跡は消しました。ほかの乗り物の軌跡、砂埃、発見物の光柱も弱めています。速度表示は小さく、粒状の画面効果は薄くしました。敵弾の幾何学模様と濃い輪郭には色調整をかけません。

視野の速度による拡大を14度から2度、ダッシュ分を7度から0.8度へ抑えました。旋回に連動する画面の傾き・横振れ・細かな振動も小さくし、道の先と遠景に目が留まる視点へ寄せます。実行時の色調整は既存のマテリアルのシェーダー内で行い、追加の全画面描画用バッファは作りません。

## 馬と音

四拍と後脚の飛節、接地と音の同期は維持します。見た目の周期は40m/sで1.54、80m/sで1.70、上限1.74周期／秒。胴体の揺れと脚の持ち上げを少し抑え、騎手の前傾を平均約7.4度から約2度へ戻しました。首・尾・帯の動きも落ち着かせています。移動速度・加速・操舵・当たり判定・任意の敵設定は変更しません。

蹄音の芯は残し、音量を約21%下げ、2.2kHzのローパスで硬い高音を和らげました。風とエンジンも控えめにして、全12曲を60〜72 BPMの静かな旅の編成へ変更します。低い弦、笛のような旋律、少ない撥弦を使い、下降句の後に旋律を置かない間を設けました。連続するドラムや低音の刻みはありません。地域別のランダム選曲・手動選択・保存は引き継ぎます。

曲は新しい小さなOgg音源を読み込み、準備後は音声クロックでループします。Vorbisを使えない環境では同じ譜面を一度生成します。切り替え先を準備する間も前の曲は続きます。詳細と再生成手順は [MUSIC.md](MUSIC.md) を参照してください。


Nodeの12試験、実際のChromiumで四肢と音の20／30／60／120fpsの一致、全12曲の合成と録音ファイルの復号、ループの継ぎ目、音割れ、準備中の取り消し、設定保存、共有音声と走行を検査しました。本体の録音では1.6秒のメインスレッド停止中も再生を維持します。馬とサイドカーは同一条件で位置・速度が一致し、馬の武器起動は抑止されます。湖・雪山・砂漠を描画してシェーダーとページのエラーも検査します。

ソフトウェア描画のブラウザー試験であり、iPhone/Safari実機の聴感・操作感・発熱時の性能は未確認です。
