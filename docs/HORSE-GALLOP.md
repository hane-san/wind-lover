# 「ぱからっ」と駆け抜ける馬（2026-10-22）

後続の背の高い馬の骨格・造形と後方カメラは [TALL-HORSE-AND-CAMERA.md](TALL-HORSE-AND-CAMERA.md) を参照してください。歩調は本書のままです。蹄音と接地エフェクトの微調整は末尾に記載します。

淡い景色と物悲しい音楽はそのまま、馬の脚と蹄音へ疾走感を戻す調整です。移動速度・加速・操舵・当たり判定は変えません。速度線、強い視野拡大、光の軌跡は復活させません。

## 比較対象と確認の限界

ユーザー指定の比較対象は[オルディン大橋での一騎打ちと騎馬戦のエポナ](https://www.youtube.com/watch?v=VB2aS9OL25w)です。ページの題名と説明は確認できましたが、今回の環境では映像・音声データを取得できませんでした。以下は「高速で疾走」「ぱからっ、ぱからっ」というユーザーの要望を基準にしたオリジナルの動きと合成音です。動画を実測した数値、動画との一致検証として扱わないでください。

## 一歩のまとまり

四本の接地を、右後肢・左後肢・右前肢・左前肢の順に、一周期の0%、7%、26%、44%へ置きました。近接した後肢二音を短い導入にし、前肢二音で輪郭を付け、その後に脚を戻す間を取ります。60m/sでは約1.91周期／秒。音の間隔は約37・100・94・294msで、一周期ごとに「ぱからっ」というまとまりを狙います。見た目の周期は40m/sで約1.76、80m/sで約2.05、上限2.12周期／秒です。

足先は前へ伸び、接地中に後方へ押し、離地後に畳んで戻します。前後方向の軌跡は接地・離地の境目で速度が急に切り替わらないようにつなぎました。前肢の前後の幅は約1.22m、後肢は約1.34m。胴の上下動は全幅約13cmにとどめます。前肢と後肢の曲がり方、後肢の飛節、四肢が浮く間を維持します。

騎手は腰で胴体の上昇と傾きの一部を吸収します。試験上、帽子の頂点の上下幅は13cm未満、胴体と合わせた前後傾は約6.3度未満。馬の動きに対して騎手の頭が忙しく跳ねず、前方を見続ける姿を狙います。首のうなずきと後ろへ流れる尾も歩調に合わせます。

蹄音は160msの短い合成音。大きな低音の衝撃を抑え、360・590・960・1480Hz付近の空洞感のある響きを中心に、道路と草地の違いを残しました。3.1kHzのローパスと既存の共通出力を使用します。BGM、風、景色、カメラの設定は変更しません。

## 接地の微調整（2026-10-22）

蹄音のゲインを0.34から0.36へ約6％上げ、ローパスを2.9kHzから3.1kHzへ開きました。四拍の間隔・音程・音源の長さは維持します。実際の音声描画ではピーク約0.183、20／30／60／120fpsの各2秒間に15接地で、発音時刻は一致しました。

`world/horse-wake.js` は各接地で小さな埃4粒と淡い種1粒を放ち、約0.34〜0.50秒で消します。埃は道路・水・土地の色を受け、道路では薄く、水では少し上に跳ねます。現在の蹄の世界座標を更新した後で発生させ、フレーム内の接地時刻に応じて位置を補正します。72粒の固定プールと1回の描画に収め、世界変更・乗り換えで消去します。停止・空中・死亡・一時停止では新たに出ません。馬のモーション、速度、カメラ、曲は変更していません。

```sh
python tests/horse-wake-browser.py --browser /path/to/chromium --three /path/to/three.min.js --out /tmp/horse-wake
```

実際のWebGLで接地数のfps間一致、蹄との位置一致、停止・空中・死亡・一時停止時の抑止、消滅・固定容量・リセットを確認し、湖・雪山・砂漠を描画します。
