# 残された無人警戒網と、戦闘の緩急（2026-10-23）

2026-10-24の[騎射と前方哨戒](BOW-RIDING.md)が、本書の武器ローテーション・弾速・馬の速度に優先します。本書は前版の設計記録です。

文明崩壊後も機械だけが警戒を続ける世界として、敵の移動、予告、発射、撤退を一つの流れにしました。最新版のカメラ調整・比較、四つの旅路、馬の手綱・踏み替え、静かな地域別BGMはそのまま引き継ぎます。本書が以前の常時襲撃・弾速・被弾処理の記述に優先します。

## 景色から戦闘へ、また景色へ

`world/encounter-director.js` がシミュレーション時間で進みます。開始直後は13秒の静かな走行。その後は下の順序です。

| 区間 | 時間と挙動 |
|---|---|
| 予告 | 2.4秒。既存のトーストと機械の起動音。編隊が遠くから接近する |
| 戦闘 | 通常26秒。8秒の武器波、2秒の発射休止、7秒の武器波、2秒の休止、7秒の武器波 |
| 撤退 | 4.5秒。新規発射と予約済みの列を止め、残弾が通過し、編隊が上昇して離脱する |
| 静かな走行 | 地域別の23〜32秒に0・2・4秒の変化。湖は長め、砂漠と都市は短め。敵弾・ミサイル・砲撃は残らない |

三つの武器波の順は遭遇ごとに変わります。空を横切る巡回機は静かな区間にも残り、攻撃しません。敵の同時主力編隊は一つ、巡回は四つまでです。手動の「襲撃：オフ」は従来どおり景色だけの走行になります。常設のゲージや新しいボタンは追加していません。

体力1では発射間隔を35%延ばし、次の休息も9秒延長。戦闘開始時から体力1なら22秒で終わり、戦闘中に体力1へ落ちたら残りを最大4秒にします。速く走り続けた22秒ごとの回復は維持。馬には体力・呼吸として表示します。停止による集中砲撃は戦闘中だけです。

屋根へ入ると発射予約・弾・ミサイルを取り消し、抜けてから12秒の猶予を置きます。急なカーブではミサイル波を実弾へ替えます。メニュー、全画面のカメラ比較、タブ非表示から再開しても、予約音が遅れて鳴りません。

## 三つの攻撃

| 攻撃 | 読むもの／避け方 | 見た目と音 |
|---|---|---|
| 幾何学弾幕 | 九種類の格子・扇・輪・直線・螺旋・門・菱形・六角形・折線。隙間を選び、そのラインを走る | 濃い外枠、暖色や氷色の面。短い硬い発射音と通過音 |
| 実弾 | 七つの固定射線へ三連射。最初の発射時に狙いを決め、その後は追尾しない。射線の間へ移る | 約4.2mの曳光、細い発光する弾頭、75ms間隔の乾いた連射音 |
| ミサイル | 約0.85秒の発射準備。発射後0.42秒で誘導を打ち切り、そこからの切り返しで外せる | 黒い弾体、尾翼、排気、薄い煙の航跡、地面の予測地点。噴射音と鋭い通過音 |

編隊は幾何学弾幕で約280m、実弾で約350m、ミサイルで約550m先を保ちます。予備動作では配置の変形を止め、目が琥珀色へ、発射時だけ短く明るくなります。機体の膨張と大きな揺れを抑え、群れの前進速度を個体にも引き継ぐため、隊列だけが先へ滑っていく見え方を抑えています。実弾とミサイルは実際の編隊の機体位置から発射します。

幾何学弾は相対速度92から108m/sへ変更。通常の前方280mで到達まで約2.6秒。実弾は相対210m/sで、約350mから約1.7秒、最低1.1秒を確保します。弾幕の列・実弾は発射後に曲がりません。ミサイルは170m/sで始まり145m/s²で300m/sまで加速。加速を含む迎撃時刻を計算し、誘導中も旋回は最大約0.85rad/sです。同時に飛ぶのは最大2発、寿命4秒。砲撃はミサイル波に限って加わり、高速走行なら着弾点を置き去りにできます。

弾・実弾は従来の半径0.32mの自機コアと相対線分の連続判定。ミサイルはそのコアに弾体分0.22mを加えた0.54mで判定し、大きい爆風判定は加えていません。グレイズは一度だけです。これらの被弾では体力1を失い、無敵1.45秒。馬の減速は6%、他車両は8%で、勝手に空中へ跳ね上げません。従来の砲撃の爆風は別の処理です。

## 描画と音の費用

弾と実弾は4608発の既存固定プールを共有。実弾の線を追加の一回で描画します。最低限の画面上の弾頭サイズを保ち、実弾を大きな菱形として表示しません。ミサイルは8個の固定プールとインスタンス描画、煙は256本の固定バッファです。視認性のため遠方の弾体を少し大きく描きますが、近くの当たり判定は変えません。

`world/weapon-audio.js` は発射・実弾・噴射・通過・命中・機械の準備音を生成。各3変奏、最大18バッファを出発時の音声初期化で準備します。最大24音、通過音は90ms以上空け、弾一発ごとに音声ノードを作りません。三連射は音声クロックへ予約し、描画のタイマーに依存させません。立ち上がり約1.8ms、末尾約9msの処理で、硬い音と不連続なクリックを区別します。メニュー・襲撃オフ・効果音オフ・世界変更・タブ非表示では予約音を滑らかに止めます。BGMと効果音は既存の独立ゲインと共通出力を使います。

実ゲームの物理・ストリーミングと攻撃を180秒進め、静かな区間に攻撃が残らないこと、三系統が実際に発射されること、上限数、屋根・オフ・低体力時の処理を調べます。実弾とミサイルそれぞれに、20/60/120fpsで「直進なら体力2、約5.16m横へ避ければ体力3」の比較を行います。先行実走では、静かな走行約81.3秒、戦闘約78秒、予告7.2秒、撤退13.5秒。幾何学弾1349発・実弾273発・ミサイル11発、最大同時弾399発・ミサイル2発でした。無敵を与えた走行は密度と路上走行の検査であり、無操作で生存できるという意味ではありません。

音声試験は6種類を実際のOfflineAudioContextで描画し、出力、先頭・末尾、最大同時音、未来へ予約した連射の中止を確認。既存の音楽録音試験でBGMの継ぎ目、描画停止、曲の切替、独立オンオフも確認します。追加されていた最新のカメラ比較も回帰検証します。

再監査では、`updateEncounters` の休息・屋根での取消、`updateDrones` の予備動作と発射予約、`kineticVolley` の狙いの固定、`WindMissiles` の誘導打ち切りと相対判定、`WindWeaponAudio.stop` の未来音の取消を重点的に確認できます。実際のスマートフォンでのFPS・発熱、タッチでの連続回避と聴感は別途確認対象です。
