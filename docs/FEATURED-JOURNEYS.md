# 三つの旅路と回避の改修

ウズベキスタンの砂漠の廃線、ビシュケクからオシュを思わせる山道、イシク・クルの湖岸を着想源にした架空の旅路です。既存の120 kmの世界に接続し、開始画面と走行中のメニューの先頭から直接出発できます。ほかの世界は折りたたんだ選択欄に残しています。

- **砂漠の廃線**：旅路の75.1 km地点から。錆びた駅、空の車両、乾いたバラストの先に、青いドームや朽ちた街の輪郭が見えます。
- **ビシュケクからオシュへ**：約17.7 kmの曲がる山道。斜面と断崖、開放型の雪崩よけギャラリー、深いトンネル、アーチの補強材を設けています。
- **イシク・クル一周**：約35.9 kmの閉じた湖岸道路。北岸・西岸・南岸・東岸が切れ目なくつながり、同じ道を何周でも回れます。水際の地形を低く整え、遠くに連続した雪山の尾根を置いています。

`world/featured-routes.js` に道路の定義、連続したサンプル、弧長、空間索引をまとめています。湖の最後の点は最初の点と同じ座標・高さで、継ぎ目が開きません。道路の描画・床・斜面の法線・トンネルの保護は同じサンプルを使用します。

## 走りと弾幕

敵弾に対する判定は半径0.32 m。自機と弾の移動を合わせた連続判定は維持しています。短い操作は横への移動を強め、離したときの滑りを早く収めます。長く倒せば通常の旋回、ブレーキと組み合わせればドリフトができます。

新しい曲線道路では、操舵で選んだ横位置を記憶し、その位置を保って曲がる補助を加えています。強い操舵では道を離れられます。道路上に風の上昇流が重なって勝手に持ち上げられないようにし、頭上の橋や屋根を自動ジャンプの対象から除いています。巡航からの加速を強め、速度に応じてカメラを少し後ろへ引き、旋回時の傾きと横振れは控えめにしています。

正面の弾幕は9種類。従来の格子・扇・輪・固定列・螺旋・二重の門に、六弁の花、二重の六角形と放射線、リサージュ曲線を追加しました。基準の相対速度は72 m/sから92 m/sへ上げ、形によって約81〜103 m/sを組み合わせます。編隊の保持距離も280 mへ伸ばし、基本の判断時間は約3秒を保ちます。発射後は追尾せず、幾何学模様の内部にも通れる隙間を残します。

弾は固定4,608枠、単一のPoints描画です。解像度が下がっても弾数・当たり判定は変えません。

## 音

初回はBGMオンです。ページを開いた時点では音声コンテキストや音源を作らず、「旅路を選ぶ」「走りはじめる」などの操作を受けて再生します。保存済みのオフ設定は尊重します。

BGMは事前生成したループを音声クロック上で再生し、曲の読み込み待ちでは前の曲を流し続けます。従来のクロスフェードと継ぎ目補正に加え、風のノイズ音源の始点・終点も一致させています。効果音には短い立ち上がりを加え、オン・オフ時の音量も滑らかに変えます。BGMと効果音は別々の音量経路を経て、共通の圧縮・ソフトクリップ出力で混合します。

## 路上の形状監査

- 隣接する区画が同じ道路・廃線を重複描画していた箇所を、線分の中心位置による単一の所有区画へ統一。
- 坂の白線の中点高さを補正し、路面から浮く短冊を修正。
- 廃線の草を通路の外へ移動。ランダムな斜板、柵、照明、バスなどが主要道へ侵入しないように配置を制限。
- 新旧道路が近い高さで接する部分は滑らかに接続。高さの異なる交差では、プレイヤーの足元に合う床を選択。
- 遠景の山は独立した三角板の列から、面がつながった複数の尾根へ変更。

## 検証

```sh
node tests/featured-routes.test.mjs
python tests/featured-browser.py --three /absolute/path/three.min.js
python tests/world-smoke.py --three /absolute/path/three.min.js
python tests/dodge-browser.py --three /absolute/path/three.min.js
python tests/music-browser.py --three /absolute/path/three.min.js
```

PythonはPlaywrightとChromium、音楽の録音解析はNumPyとFFmpegを使用します。`--three` はCDNの代わりにローカルのThree.js r128を使うための任意指定です。

新しい旅路の試験は全サンプルの床・勾配・周回の継ぎ目、各目的地へのメニュー移動、実走行、トンネル・湖岸の描画面と物理面の一致、通路上のコライダー、道路の重複三角形、非有限座標を調べます。山道と湖は長い通し走行も実施します。画面と結果は `/tmp/wind-featured-qa/` に保存します。

音楽試験は4曲を実際のループ終端付近から再生して継ぎ目を録音し、描画処理の1.6秒停止と曲の切替を含む出力で100 ms以上の無音や大きな不連続を調べます。風のループの始点・終点も比較します。スマートフォン実機の発熱時のFPS、Bluetooth・通話からの音声復帰は未測定です。

Claudeでの再監査では、道路サンプルの高さ、旧道路との交差、`roadAffinity` の横位置維持、`featuredWalls` の描画との一致、幾何学模様の隙間、共通の音声出力を確認できます。現実の地理の縮尺・道路形状の再現を目的としたデータではありません。

通し試験の最終結果は、山道約17.1 km・湖岸約36.0 kmをどちらも装甲3のまま完走、道路中心からの最大偏差はそれぞれ約0.8 m・約2.7 mでした。主な3地域の近傍メッシュでは非有限頂点・道路の重複三角形はゼロ。音の録音では約7秒の試験区間で100 ms以上の無音はなく、風の始点・終点も一致しました。これはブラウザ試験の測定値で、実機の滑らかさを保証する数値ではありません。
